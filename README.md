# Светлячок («Изгиб Питона»)

Детская игра-змейка про энергосбережение. В светлом дневном лесу Питоша
собирает выключатели: каждый гасит одно окно в домиках. Окна остаются
выключенными до новой партии. При сборе выключателя день плавно сменяется
ночью; через 5 секунд снова наступает утро. Следующий выключатель снова
запускает ночь. На паузе смена времени суток останавливается.
На стартовом экране доступны два режима:
- **Спасти деревню** — выключить 12 окон и победить. После самоукуса змейка
  снова становится короткой, собранные выключатели сохраняются.
- **Бесконечная ночь** — собирать выключатели до самоукуса. Каждые 12 окон
  начинается следующая деревня, длина и счёт сохраняются. Скорость растёт
  до безопасного предела. Заполнение всего поля завершает игру победой.
  Личный рекорд сохраняется в браузере, если доступно локальное хранилище.

Выбор режима: кнопки на экране, клавиши 1 / 2 или Tab; Enter — начать.
На паузе и после завершения можно вернуться к выбору режима.
Escape ставит игру на паузу, повторное нажатие возвращает в меню.

Играть онлайн: https://dxbrkt.github.io/snake-svetlyachok/

## Запуск на компьютере

```bash
pip install pygame
python the_snake.py
```

Управление: стрелки (или WASD), на телефоне — свайпы. P или пробел — пауза.

Справа от поля — «Лесное радио» с тремя песнями. Нажмите ▶, чтобы включить
музыку; кнопки по бокам переключают песни, ползунок меняет громкость.
После окончания песни включается следующая, плейлист повторяется по кругу.
Клавиши: M — музыка/пауза, [ и ] — предыдущая/следующая песня,
− и = — тише/громче. Музыка продолжает играть во время паузы игры.

## Веб-версия

`tools/build_web.sh` собирает игру через pygbag в папки `build/web` и `docs/`
(из `docs/` работает GitHub Pages).
Музыка в браузере воспроизводится нативным аудиоплеером независимо от
игрового цикла. При уходе с вкладки или открытии диалога закрытия звук
ставится на паузу; при возврате продолжается с того же места.
Ручная пауза сохраняется. Файлы `audio.js` и `audio/` входят в веб-сборку.

Проверка: `SDL_AUDIODRIVER=dummy venv/bin/python -m pytest -q` и
`node --test tests/web_audio.test.cjs`.
